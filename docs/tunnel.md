# Cloudflare Tunnel для локальної студії

Тунель потрібен, щоб APIMart міг отримати локальне відео/аудіо або надіслати webhook. **Один публічний HTTPS-origin може бути значенням обох змінних:** `MEDIA_BASE_URL` і `WEBHOOK_BASE_URL`. Звичайна генерація з тексту з polling, локальний перегляд і завантаження результатів працюють без нього.

## Запуск

Запустіть студію й установіть `cloudflared` за [офіційною інструкцією](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/downloads/). В окремому терміналі виконайте:

```sh
cloudflared tunnel --url http://127.0.0.1:3001
```

Скопіюйте виданий HTTPS-origin до локального `.env`, **без `/callback` та інших шляхів**:

```dotenv
MEDIA_BASE_URL=https://your-tunnel.trycloudflare.com
WEBHOOK_BASE_URL=https://your-tunnel.trycloudflare.com
```

APIMart сам додає `/callback` до параметра `webhook`. Для роботи лише з медіафайлами залиште `WEBHOOK_BASE_URL=` порожнім — генерації перевірятимуться polling.

Збережіть файл і застосуйте налаштування. Для вже зібраного Docker Compose:

```sh
docker compose up -d --no-deps --wait api worker
```

При першому запуску або зміні коду використовуйте `docker compose up -d --build`. Для `npm run dev` зупиніть і запустіть команду знову.

У локального референсу, який чекає на URL, натисніть **«Повторити підготовку»**. Дочекайтеся готовності в бібліотеці, після чого можна запускати Edit чи генерацію з відеореференсом. Адреса webhook передається під час створення **нової** задачі; адреса вже відправленої задачі автоматично не змінюється.

## Чому порт 3001

Окремий listener містить лише:

- `POST /callback` — приймання сигналу для перевірки статусу задачі;
- `GET /reference/:id/:token` — отримання конкретного референсу за тимчасовим токеном, з підтримкою byte ranges.

Інтерфейсу, балансу, історії операцій і SSE тут немає; `/`, `/api/state` та `/api/events` повертають 404. Основна студія залишається на [localhost:3000](http://localhost:3000). Якщо змінили `CALLBACK_PORT`, спрямуйте тунель на новий опублікований порт.

Тимчасове посилання на референс діє 24 години. Це не обмежує строк зберігання локальної копії: збережений файл можна підготувати повторно. Зовнішній доступ потрібен, доки провайдер отримує файл для своєї бібліотеки.

## Завершення та повторний запуск

Термінал із `cloudflared` має залишатися відкритим. **Ctrl+C** зупиняє цей тунель; локальна студія й збережені відео продовжують працювати. Сон комп’ютера або втрата інтернету переривають доступ до ще не отриманих провайдером файлів і доставку callback. Polling залишається резервною перевіркою.

Quick Tunnel має тимчасову випадкову адресу. Після нового запуску оновіть обидві змінні `.env`, перезапустіть застосунок і за потреби повторіть підготовку референсу. Якщо webhook старої задачі не дійде на попередню адресу, її статус перевірить polling.

Quick Tunnel використовується для локальної розробки й демонстрації. Для постійного розгортання потрібні стабільна адреса, керований запуск сервісів і відповідне сховище файлів. Докладніше: [Cloudflare Quick Tunnels](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/trycloudflare/).
